# gym_workout_plan

A Flutter application for managing gym workout plans.

## How to Run the Project

Follow these steps to run the project locally:

1. **Prerequisites**
   Ensure you have the [Flutter SDK](https://docs.flutter.dev/get-started/install) installed on your machine.

2. **Install dependencies**
   Run the following command in the project root directory to fetch all required packages:
   ```bash
   flutter pub get
   ```

3. **Run the application**
   Start the app on your connected device, emulator, or simulator:
   ```bash
   flutter run
   ```
